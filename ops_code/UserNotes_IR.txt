10/28/2025
Error: You want ppglider environment to be easily accessible.

Solution: ppglider is the environment that has been installed with the .yml file. To easily enter that environment (which is what you should do before running other gliderPP python code) you need to activate it. To set up an easy way to activate, the following should go be entered into the terminal: 
 source ~/anaconda3/etc/profile.d/conda.sh
 conda --version
conda 25.5.1
 conda activate ppglider
(ppglider) funkb@funkb-Legion-Pro-5-16ARX8:~$ conda init bash

You can now close the terminal. Now whenever you open a terminal in the future, you can run the command: 
conda activate ppglider
and you can now run the pipeline with hopefully most of the python packages installed.

FileNotFoundError: [Errno 2] No such file or directory: '/home/funkb/Documents/GliderPP/tmp/A2018123.L3m_DAY_PAR_par_4km.nc' -> './dap/PAR/A2018123.L3m_DAY_PAR_par_4km.nc'


The SOLUTION was: 
Problem:
Downloading NASA OceanColor PAR (.nc) files failed because the original wget calls did not handle Earthdata authentication properly.
wget requests were redirected through Earthdata’s OAuth system, requiring proper .netrc credentials and cookies.

Solution Steps:
Create a .netrc file with your Earthdata credentials:

machine urs.earthdata.nasa.gov
    login your_username
    password your_password

Saved with nano ~/.netrc and set permissions chmod 600 ~/.netrc.
Modify download_tools.py (get_remote function):
Added a wget command using .netrc and cookies for authentication:
wget --quiet --load-cookies ~/.urs_cookies \
     --save-cookies ~/.urs_cookies --keep-session-cookies \
     --netrc-file ~/.netrc -O local_file.nc url


Process the downloaded file locally:
Subset the PAR file with ncks to the desired lat/lon box.
Add a time dimension with ncap2.
Create a record dimension using ncecat.
Rename and store in the target directory with proper permissions.

Result:
PPGlider successfully downloads PAR files from NASA OceanColor.
Files are automatically subset, time-tagged, and ready for concatenation into a data cube.

✅ Key points:

.netrc + wget handles Earthdata authentication.
Processing remains local to avoid repeated downloads or permission issues.
This framework can be extended to other NASA or CMEMS datasets.
